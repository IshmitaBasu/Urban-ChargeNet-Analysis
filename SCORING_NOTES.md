# Screening rubric

This is an exploratory shortlist, not a demand forecast, investment recommendation, or confirmation that a site can host a charger.

`weighted_score = 0.6 × coverage_gap_score + 0.4 × activity_score`

Coverage gap is based only on straight-line distance to mapped OSM charging stations: under 1 km = 1; 1–1.5 km = 2; 1.5–2 km = 3; 2–3 km = 4; 3 km or more = 5. A mapped count within 1 km is retained as context. This measures map coverage, not confirmed supply or driving distance.

Activity scores are analyst-assessed from the mapped type: RDB Boulevard (mall) = 5; the parking near RDB Boulevard = 3; the other mapped parking = 2 because no activity detail was supplied by OSM. They can be changed in the workbook.

The traffic data is only context for the Webel More intersection. It is not used as a score for any candidate. Results can change with the weights, OSM coverage, and site inspection. Land access, parking permissions, grid capacity, actual EV use, and site traffic must be verified before any investment decision.
